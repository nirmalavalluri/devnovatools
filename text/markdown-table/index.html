📖 What is this tool?

Markdown Table Generator converts CSV, TSV (tab-separated, like data copied straight from Excel or Google Sheets) or pipe-delimited data into a properly formatted GitHub-flavored Markdown table — with columns padded and aligned so the raw source is readable too, not just the rendered output.

💡 Example

Input
name,age,city Alice,30,NYC Bob,25,LA
Output
| name | age | city | | ----- | --- | ---- | | Alice | 30 | NYC | | Bob | 25 | LA |

🛠️ Common Use Cases

  • Turning a spreadsheet range into a table for a README or wiki page
  • Converting API or database query results into documentation tables
  • Building comparison tables for blog posts or GitHub issues
  • Formatting CSV exports for pull request descriptions

❓ Frequently Asked Questions

What input formats does this tool accept? ▾
CSV (comma-separated), TSV (tab-separated, e.g. pasted directly from Excel or Google Sheets), and pipe-delimited data. The delimiter is detected automatically from the first line.
Does it handle commas inside quoted fields? ▾
Yes. Fields wrapped in double quotes can contain commas, newlines, or escaped double quotes ("") and are parsed correctly, matching standard CSV quoting rules.
Why are the columns padded with extra spaces? ▾
Markdown doesn't require aligned columns in the source, but padding every cell to the same width makes the raw .md file readable as a table before it's even rendered. Rendered output is identical either way.
🔒
Your data stays private. All processing happens entirely in your browser. Nothing is ever sent to our servers. You can use this tool offline after the page loads.
