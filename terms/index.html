3. Tool-Specific Disclaimers

Certain categories of tools carry additional limitations you should be aware of:

  • Hash & Crypto Tools: MD5 and SHA-1 are cryptographically broken for security purposes. For secure hashing, always use SHA-256 or higher. Do not use hash outputs as a substitute for proper security audits.
  • AES Encryption: Our encryption tool uses the Web Crypto API for client-side encryption. While robust, it is intended for educational and testing use. Do not use it as your only layer of security for highly sensitive data.
  • Network Tools: DNS, SSL and IP lookup tools query third-party public APIs. Results may be delayed, cached, or incomplete. Do not make critical infrastructure decisions based solely on these results.
  • Generator Tools: Values generated (UUIDs, passwords, tokens) are created locally in your browser and are not stored or logged by us. Uniqueness and randomness quality depend on your browser's implementation.
  • Code Formatters & Linters: Formatting and linting results are provided for convenience. Always review output manually before deploying to production environments.
  • Diagramming Tools: Diagrams are rendered using Mermaid.js. Complex or malformed syntax may not render as expected.
