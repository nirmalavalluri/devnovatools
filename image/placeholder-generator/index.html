📖 What is this tool?

Placeholder Image Generator creates custom placeholder images for mockups, wireframes and development. Set custom dimensions, background color and text color, then get the image URL, HTML, Markdown and CSS snippet all at once.

❓ Frequently Asked Questions

What sizes can I generate? ▾
Any width and height from 1px to 2000px. Common sizes: 1920×1080 (HD), 1200×630 (OG image), 800×600 (standard), 300×250 (banner ad), 100×100 (avatar).
Can I add custom text to the placeholder? ▾
Yes — enter any text in the "Custom Text" field. Leave it blank to automatically show the dimensions (e.g., "800×400"). Text is centered on the image automatically.
Can I use these images in production? ▾
Placeholder images should only be used during development. For production, replace them with real images. The via.placeholder.com service may have rate limits or downtime.
