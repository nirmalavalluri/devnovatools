## 🔒 Why DevNova Tools?

Most online developer tools have one or more of these problems:

- ❌ Require you to create an account just to use them
- ❌ Send your JWT tokens, JSON, API keys or passwords to a server
- ❌ Show ads that slow the page down
- ❌ Break when you're offline or on a VPN

**DevNova Tools is different.** Every single tool runs as client-side JavaScript in your browser. Your data never leaves your computer. Disconnect from the internet after the page loads — everything still works.

## 🚀 Getting Started

No installation needed. Just open any tool in your browser:

```
https://devnovatools.com
```

All tools work immediately — no account, no setup, no extensions.

**Works offline too:** After visiting a tool page once, it runs without internet. Perfect for secure or air-gapped environments.

---

## 🏗️ Tech Stack

- **Frontend:** Vanilla HTML, CSS, JavaScript — no heavy frameworks
- **Processing:** 100% client-side — all logic runs in the browser
- **Hosting:** Deployed via CDN for fast global load times
- **Privacy:** No analytics on tool usage, no cookies for tool data
